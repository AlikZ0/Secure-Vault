# Исправления и проверка на iPhone

- Вход: по запуску автоматически появляется Face ID / Touch ID / системный код устройства. Ручная кнопка показывает поддерживаемый способ.
- Одна проверка личности: один `LAContext` сначала проходит `evaluatePolicy`, затем используется для доступа к тому же ключу Keychain.
- При уходе в фон доступ блокируется; по возвращении можно снова разблокировать. При нажатии замка ручная блокировка остаётся до следующего нажатия на кнопку.
- Иконка: `SecureVault/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon.png`, имя набора `AppIcon` в `project.yml`. Workflow проверяет скомпилированный `Assets.car` и `Info.plist`.
- Запуск: asset `LaunchMark` на фоне `LaunchBackground`.

**На iPhone:** обнови установленное приложение без удаления данных. Если иконка остаётся старой после обновления — перезагрузи iPhone и проверь установленный IPA; перед удалением приложения сохранение данных не гарантируется.

**Сценарии:** Face ID доступен; Touch ID доступен; биометрия выключена, но код устройства есть; отмена системной проверки; ручная блокировка; возврат после фонового режима; отсутствие код-пароля; повторное открытие существующих записей.

Сборка не запускалась на macOS в этом окружении.
